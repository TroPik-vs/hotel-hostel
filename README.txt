HOTEL & HOSTEL PROJECT

INSTALLATION:
1. Install XAMPP.
2. Extract this ZIP.
3. Copy the hotel-hostel folder to:
   C:\xampp\htdocs\
4. Start Apache and MySQL in XAMPP.
5. Open phpMyAdmin: http://localhost/phpmyadmin
6. Import: hotel-hostel/database/hotel_db.sql
7. Open: http://localhost/hotel-hostel/

ADMIN LOGIN:
URL: http://localhost/hotel-hostel/admin/
Username: admin
Password: admin123

The Admin Panel is protected by login.
